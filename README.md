# scoreicon

Score filesystem icon paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/scoreicon/

## Install / run

```bash
git clone https://github.com/theworker02/scoreicon.git
cd scoreicon
node src/cli.js
node --test
```
